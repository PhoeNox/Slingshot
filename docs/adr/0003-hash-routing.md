# Hash routing

Each screen has a URL hash route: `#/` for the main menu, `#/play-menu` for choosing hot-seat or hosting, `#/play` for a hot-seat match, `#/settings`, `#/credits`, `#/host` for hosting a remote match, and `#/join/<offer code>` for an invitation, whose route carries the host's offer code. The site is served from GitHub Pages under a subpath, and Pages has no fallback for unknown paths, so History API paths would 404 on reload without a `404.html` redirect workaround. Hash routes need no server support. Leaving `#/play` abandons the match, reloading it starts a fresh one, and an unknown hash (including `#/join/` with no offer code) is replaced with `#/`. The invitation route accepts any non-empty offer code; the guest screen decides whether it is valid.
